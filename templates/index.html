Como funciona

Um pipeline ETL coleta os dados diretamente das APIs oficiais, processa e armazena localmente. O Flask serve os dashboards sem dependência de infraestrutura externa.

1
Coleta automática via API

O módulo extract.py consulta a API REST do SICONFI (Tesouro Nacional), obtendo os dados do RREO em formato JSON padronizado para todos os entes federativos.

2
Processamento e armazenamento

Os dados são agregados por função de governo e salvos em JSONs anuais em database/{UF}/ — uma subpasta por estado. O histórico é acumulado sem sobrescrever anos anteriores.

3
Visualização interativa

O Flask entrega os dashboards com Chart.js. A troca de ano e esfera acontece via AJAX — sem recarregar a página. O gráfico de evolução histórica é carregado automaticamente com todos os anos disponíveis.
